as the style reference for all mobs: expressive fitted eyes/brows/muzzle, broad
leaf ears, compact powerful proportions and coherent rounded planes with brown
leather/simple metal. Source: existing local generated cover
`yandex-output/store-assets/source/ruinstead-cover-lowpoly.png`; promotional art,
not gameplay evidence. Preserve species anatomy and functional requirements.
Hero Path RPG / XP Hero remain the world/gameplay comparators.

Earlier cover-based environment suggestions remain supplementary, as recorded
in [VISUAL_BACKLOG](../../VISUAL_BACKLOG.md). The explicit creature scope above
does not replace world/gameplay comparisons or promise absent features. A new
local crop/reference should retain source/date, intended scope and whether it is
gameplay or promotional art; do not treat a temporary attachment path as a durable
reference asset. Store reusable permitted reference files here when needed,
