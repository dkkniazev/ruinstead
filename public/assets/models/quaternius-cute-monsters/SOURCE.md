# Quaternius Cute Animated Monsters

Selected animated creature models in this directory come from the **Cute Animated Monsters Pack** by Quaternius.

- Official source: https://quaternius.com/packs/cutemonsters.html
- Original release: August 2020
- Formats include glTF
- License: Creative Commons Zero (CC0)
- Repository mirror used to vendor the standalone embedded glTF exports: `agentkaerf/FreeModels`

The game keeps its procedural creature model as a runtime fallback if a model cannot be loaded.
