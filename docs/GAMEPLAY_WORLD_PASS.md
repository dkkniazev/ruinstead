## Найденные причины

- ResourceSystem.update раньше делал return при threatened; ChestSystem.update делал то же,
  затем автоматически выдавал лут по расстоянию и вызывал модальную рекламу.
- GameUI перехватывал KeyE в capture и всегда открывал forge. Phaser имел отдельный E для моста.
- Прокачка героя была отключена в UI по nearForge + forgeRestored и в WorldScene по restored.
- Орбитали проверяли цель от текущей точки на орбите, урон был мгновенным, mesh был лишь эффектом.
- RegionGateSystem строит shoreline из квадратов 84×84 каждые 68 единиц, corridor walls
  из квадратов 96×96 по всей длине passage включая сушу; это кандидаты на залипание/невидимые стены.
- BridgeSystem имеет отдельный legacy blocker 95×330 в центре 1–2.
- EnemyUnit сразу наносит урон при первом входе в range и moveTowards идёт напрямую к spawn.
