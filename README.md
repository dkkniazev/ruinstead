# Ruinstead

Браузерная action RPG для Яндекс Игр: исследование восьми регионов, автоатаки
основным и орбитальным оружием, добыча, развитие героя и восстановление поселения.
Phaser отвечает за сцены и игровую физику, Three.js — за 3D-представление, DOM — за HUD.
Есть русский/английский интерфейс, клавиатура и touch. Node.js ≥20.19.

## Локальный запуск

```powershell
npm ci
npm run dev
```

Открыть адрес Vite. Клавиши WASD/стрелки — движение, Space — рывок,
E — показанное ближайшее взаимодействие. Атака/сбор автоматические.
На телефоне используются джойстик и экранные кнопки; ориентация горизонтальная.
Вне Яндекса production не выдаёт фиктивные награды или покупки; mock providers
ограничены DEV. DEV preview страницы не входят в production-сборку.

## Проверки и сборка

```powershell
npm run check:docs
npm run typecheck
npm run build
```

Игровые, платформенные, художественные и release gates выбираются по
[QA_RELEASE](docs/specs/QA_RELEASE.md). `npm run release:pack` создаёт локальный
ZIP и manifest, но не запускает весь набор проверок и не публикует игру.
Ни сборка, ни зелёный CI сами по себе не означают готовность к модерации.
