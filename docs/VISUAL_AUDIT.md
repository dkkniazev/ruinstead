## Единый источник

В мире и портретах вызывается один createCreature. Идентичность, описание и точное назначение ассета находятся в CreatureCatalog.ts. HP и урон бестиария читаются из вычисленных определений EnemySystem/BossSystem. Радиус тела модели нормализуется по combatRadius. Крылья, хвосты и оружие выступают за радиус корпуса. Следующим проходом увеличен Мшистый громила, добавлены столкновения между мобами и безопасные площадки боссов — см. POLISH_PASS.md.

На момент первоначального осмотра применялись GLB Bat/Goat/Owl. В актуальном
CreatureCatalog все идентичности используют авторские модели/поверхности;
старые GLB оставлены для совместимости и rig-проверок. Локальные элиты имеют
дополнительную анатомию/экипировку и ауры. Это изменение реализации, а не
подтверждение художественной приёмки всех видов.

## Переименования

- cliff-ram: Скальный баран → Горный козёл. Модель Goat имеет силуэт козла; элита Камнерог сохранена.
- dust-vulture: Пыльный стервятник → Пустынный филин; элита → Краснокрылый филин. Модель Owl изображает сову.
- Внутренние ID сохранены, миграции сохранений не нужны.

## UI

Единый набор GameIcons, панели GameUI и GameUI.css: HUD, пять слотов оружия, фильтры типов и сортировка, рюкзак/склад, характеристики/мастерство, кузница/слияние, поселение, бестиарий/награды, сундуки/припасы/покупки, облики/фрагменты/спутники/темы, задания, звук/облако, возвращение домой, смерть и награда за босса/сундук. Карта использует тот же стиль; редкие ресурсы и ориентиры отделены фильтрами.

Списки оружия прокручиваются отдельно от блока действий. Оружие улучшается у
восстановленной кузницы; характеристики героя теперь доступны независимо от неё.
Панель кузницы открывается рядом; обработчик слияния отдельно дальность не проверяет.
HUD сохраняет интерактивные DOM-узлы. При HP ≤40% выделяется зелье, рядом показывается
здоровье; здания подписаны. Приёмку актуального HUD проводить по UI_UX_LOCALIZATION.

## Удалённое

Удалены четыре неиспользуемых Gobkit minion GLB, хеш-подбор моделей, старая система портретов бестиария, прямоугольный Phaser HUD. Старые текстуры противников сохранены как техническая основа невидимых Arcade-коллайдеров и резервного 2D-режима.

## Проверки

- npm run typecheck / npm run build
- npm run check:world / npm run check:gameplay / npm run balance
- node scripts/visual-sanity.mjs
- creature-preview.html: все 8 регионов, обычные виды, элита и боссы.
- ui-preview.html: 150 вариантов оружия, открытые записи бестиария, большие значения и длинные русские названия; состояние не сохраняется и не вызывает SDK.
- Браузер: телефон 844×390, планшет 1024×768, стандарт 1280×720; все основные меню, награды, карта, сортировка и выбор последнего оружия.

## Ограничения

Процедурные существа имеют базовую артикуляцию ходьбы/крыльев/тела, а не индивидуально поставленные скелетные клипы каждого из 64 видов. Художественная детализация проще Hero Path. Физическое сенсорное устройство не проверялось. Реальные оплаты/реклама Яндекса не запускаются при локальной визуальной проверке; вне площадки SDK сообщает о локальном режиме. Production build проходит с предупреждением Vite о крупном JS-файле (~623 КБ gzip).
