## Локальный кандидат

Пересобрать: `npm run release:pack`.

Загрузить в черновик **содержимое архива**
`D:\Yandex\ruinstead\yandex-output\ruinstead-candidate.zip` через загрузку ZIP.
У `index.html` нет внешней папки-обёртки. Файлы DEV preview в архив не входят.
Последний SHA256 и список файлов находятся в соседнем `.json`.

Настройки текущего кандидата:

| Поле | Значение / состояние |
| --- | --- |
| Название | Ruinstead |
| Языки | Русский (`ru`) и английский (`en`); выбор через `environment.i18n.lang` SDK |
| Ориентация | Горизонтальная |
| Устройства | Десктоп, iOS, Android по выбору пользователя; полный телефонный QA ещё не завершён |
| ТВ | Не проверено, не заявлять |
| SDK | `/sdk.js`, Game Ready после подготовки мира |
| Реклама | Rewarded по действию игрока; interstitial отключён в конфигурации |
| Сохранение | Локальное; облачное для подключённого Yandex ID |
| Публикация | Только черновик для QA до закрытия оставшихся проверок |

Иконка 512×512, обложка 800×470 и русский текст карточки сохранены в черновике:
см. `STORE_CARD_RU.md`. PNG из `yandex-output/store-assets` загружаются в поля
карточки отдельно от ZIP игры. Русская галерея содержит семь кадров для каждой
платформы, английская — пять. Есть бой с обычными врагами и лавовым големом,
высоты, каньон и восстановленное поселение. Все кадры — реальные JPEG 1280 × 720.
Подробности профиля съёмки — в `LOCALIZATION.md`; английские тексты —
в `store-card-en.json`. Видео остаётся в состоянии обработки.

## Проверка на площадке

Работать с новым тестовым сохранением. Записывать браузер, устройство, шаги,
ожидаемый и фактический результат. Пока все пункты ниже не проверены,
локальные SDK fixtures не считаются подтверждением интеграции.

1. Холодный запуск: загрузка заканчивается, управление доступно, Game Ready
   отправлен после готовности сцены; старт без debug-параметров и усилений.
2. Rewarded: пользователь подтвердил проверку рекламы. При дальнейшей проверке
   отдельно учитывать успешный просмотр, пропуск, отсутствие рекламы и ошибку.
   Только успешный просмотр выдаёт одну награду; повторное закрытие не выдаёт
   вторую. Во время ролика движение, бой и звук приостановлены.
3. Пауза: свернуть вкладку во время рекламы; закрытие ролика не возобновляет
   игру, пока вкладка скрыта. Вернуться — управление и звук восстанавливаются.
4. Сохранения: добыть ресурс/прокачать здание, перезагрузить; повторить после
   входа в Yandex ID и открыть на втором устройстве. Новое локальное состояние
   не должно откатываться из-за старого облачного ответа.
5. Каталог: проверить настоящие цену/валюту/иконку. В тестовом режиме платежей
   площадки проверить отмену, успешную квитанцию, незавершённую покупку после
   перезапуска и однократную выдачу. Реальные платежи здесь не выполнялись.
6. Телефон: движение, зелье, добыча и сундук, меню и клавиатура/поворот экрана;
   20 минут боя, FPS/память/нагрев, сворачивание и возвращение. Эмуляция размера
   окна не заменяет этот пункт.
7. Обычное прохождение: новая игра до финального региона без QA-усиления;
   отдельно фиксировать время открытия регионов, дефицит кристалла/волокна,
   доступность улучшений сумки и отсутствие обязательного ресурсного тупика.
